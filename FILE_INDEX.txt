================================================================================
                          SETUP INSTRUCTIONS
================================================================================

STEP 1: INSTALL XAMPP
- Download from https://www.apachefriends.org/
- Install with default settings
- Start Apache and MySQL services

STEP 2: COPY PROJECT
- Copy entire "TEST CODE" folder to C:\xampp\htdocs\
- Ensure all files are present

STEP 3: SETUP DATABASE
- Open http://localhost/phpmyadmin
- Click "Import" tab
- Select db/db.sql file
- Click "Go" to import

STEP 4: CONFIGURE PHP
- Open php/contact.php
- Update lines 20-23 with your database credentials:
  * DB_HOST: 'localhost' (usually)
  * DB_NAME: 'contact_db'
  * DB_USER: 'root' (default XAMPP)
  * DB_PASS: '' (empty for default XAMPP)

STEP 5: CUSTOMIZE & TEST
- Replace all placeholders (colors, site purpose)
- Add your images
- Visit http://localhost/TEST CODE/
- Test all pages and contact form

================================================================================
                          TROUBLESHOOTING
================================================================================

ISSUE: Database connection failed
SOLUTION: 
- Check MySQL is running in XAMPP
- Verify credentials in php/contact.php
- Ensure contact_db database exists

ISSUE: 404 error on form submission
SOLUTION:
- Verify project is in htdocs folder
- Check Apache is running
- Verify path to php/contact.php is correct

ISSUE: Form validation not working
SOLUTION:
- Check browser console for JavaScript errors
- Verify js/app.js is loading
- Clear browser cache

ISSUE: Images not loading
SOLUTION:
- Check images exist in assets/images/
- Verify file names match HTML
- Check file permissions

ISSUE: Mobile menu not working
SOLUTION:
- Check browser console for errors
- Verify js/app.js is loaded
- Test in different browsers

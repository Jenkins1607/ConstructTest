## 🎨 CUSTOMIZATION

### To Add More Projects:
1. Copy any `<article class="portfolio-item">` block
2. Change the `data-category` attribute
3. Update the gradient colors in `style` attribute
4. Change the SVG icon
5. Update title, description, and tags

### To Change Colors:
Each project has inline style with gradient:
```html
<div class="portfolio-placeholder" style="background: linear-gradient(135deg, #color1, #color2);">
```

### To Add New Categories:
1. Add new filter button with `data-filter="category-name"`
2. Add `data-category="category-name"` to project items
3. JavaScript will handle filtering automatically

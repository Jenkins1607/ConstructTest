## QUICK START GUIDE

### 1. CUSTOMIZE COLORS
Edit `css/styles.css` lines 6-9:
- Replace [Primary color hex] with your primary color (e.g., #3498db)
- Replace [Accent color hex] with your accent color (e.g., #e74c3c)
- Replace [Neutral color hex] with your neutral color (e.g., #2c3e50)

### 2. UPDATE SITE PURPOSE
Find and replace in ALL HTML files:
- Find: [Site purpose]
- Replace: Your actual site name/purpose

### 3. SETUP DATABASE
1. Install XAMPP
2. Start Apache and MySQL
3. Open http://localhost/phpmyadmin
4. Import db/db.sql
5. Update database credentials in php/contact.php

### 4. ADD IMAGES
Place your images in assets/images/:
- placeholder.jpg (for lazy loading)
- about-placeholder.jpg
- team-1.jpg, team-2.jpg, team-3.jpg
- portfolio-1.jpg through portfolio-9.jpg

### 5. TEST LOCALLY
1. Copy project to C:\xampp\htdocs\
2. Visit http://localhost/TEST CODE/
3. Test contact form
4. Check logs/errors.log if issues occur

## FILES EXPLANATION

### HTML FILES
- **index.html**: Homepage with hero, features, and CTA sections
- **about.html**: Company story, mission/vision, team members
- **services.html**: Service offerings with detailed cards
- **portfolio.html**: Project gallery with filtering and lazy loading
- **contact.html**: Contact form with validation and CSRF protection

### CSS
- **styles.css**: Complete styling system with:
  - CSS custom properties (variables)
  - Mobile-first responsive design
  - Flexbox and Grid layouts
  - Smooth transitions and hover effects
  - Print-ready styles

### JAVASCRIPT
- **app.js**: Client-side functionality:
  - Mobile menu toggle with animation
  - Form validation with real-time feedback
  - Lazy loading using Intersection Observer
  - Portfolio filtering
  - Smooth scrolling
  - Debounce utility function

### PHP
- **contact.php**: Backend processing:
  - POST request handling
  - CSRF token validation
  - Input sanitization (XSS prevention)
  - Server-side validation
  - PDO database connection
  - Prepared statements (SQL injection prevention)
  - Error logging
  - JSON response format

### DATABASE
- **db.sql**: Complete database setup:
  - Database creation (contact_db)
  - Table structure (contacts)
  - UTF8MB4 charset
  - Proper indexes
  - Sample data
  - Useful management queries
